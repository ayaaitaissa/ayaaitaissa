1. Précurseurs et idées fondatrices

Vannevar Bush — Le Memex

Vannevar Bush propose en 1945 le Memex, une machine permettant de relier des documents entre eux.

Même si le Memex était davantage un appareil mécanique qu’un outil numérique, il a servi de référence conceptuelle aux idées d’hypertexte et de recherche documentaire.

Ted Nelson — Le concept d’« hypertexte »

Dans les années 1960, Ted Nelson formalise le terme hypertexte et conçoit le projet ambitieux Xanadu.

2. Naissance du Web

1989–1991 : Tim Berners-Lee au CERN

Tim Berners-Lee propose au CERN un système pour partager des documents entre chercheurs grâce à l’hypertexte et à Internet.

  • HTML : structure des documents.
  • HTTP : protocole d’échange client–serveur.
  • URL : mécanisme d’adressage des ressources.

Exemple d’un code HTML : <p>Hello world</p>

En 1991, la première page Web est mise en ligne. Tim Berners-Lee publie également les premiers logiciels de serveur et de navigateur web, posant ainsi les bases du World Wide Web moderne.

3. Le Web sémantique et Solid

Le Web sémantique

Le Web sémantique rend les données compréhensibles par les machines grâce à RDF, OWL et SPARQL.

  • RDF (Resource Description Framework): modèle en triplets (sujet / prédicat / objet) pour représenter les données.
  • OWL: ontologie permettant de définir des vocabulaires et des relations complexes entre concepts.
  • SPARQL: langage de requête pour interroger des graphes RDF.
  • Microformats et JSON-LD: moyens d'encoder des métadonnées directement dans les pages web pour faciliter l'indexation et l'interopérabilité.

Linked Data

Le concept de Linked Data consiste à publier des données ouvertes interconnectées.

Solid (Social Linked Data)

Solid est une initiative de Tim Berners-Lee visant à redonner le contrôle des données personnelles aux utilisateurs.

Avantages

  • Autonomie des utilisateurs (meilleur contrôle et réutilisation des données).

Cas d’usage

Three paradigm shifts we need to prepare for :

  • End users become data controllers.
  • Apps become views.
  • Interfaces become queries.

Exemples : moteurs de recherche enrichis, assistants vocaux, bibliothèques numériques, etc.

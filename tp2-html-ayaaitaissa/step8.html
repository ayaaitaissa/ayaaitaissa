3.Le Web sémantique, Linked Data et Solid

Le Web sémantique : objectifs et concepts

Le Web sémantique est une extension du Web actuel visant à rendre les données compréhensibles par les machines.

  • RDF (Resource Description Framework): modèle en triplets (sujet / prédicat / objet) pour représenter les données.
  • OWL: ontologie permettant de définir des vocabulaires et des relations complexes entre concepts.
  • SPARQL: langage de requête pour interroger des graphes RDF.
  • Microformats et JSON-LD: moyens d'encoder des métadonnées directement dans les pages web pour faciliter l'indexation et l'interopérabilité.

le Web sémantique vise à rendre les contenus compréhensibles par les machines, facilitant ainsi la recherche avancée, l'intégration de données hétérogènes et le développement d'applications intelligentes.

Linked Data

Le concept de Linked Data consiste à publier des données ouvertes (Open Data) sous forme de liens interconnectés pour permettre leur réutilisation par tous.
